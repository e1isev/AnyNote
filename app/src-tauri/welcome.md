AnyNote keeps your notes on this computer, in an open format you can read without it. Here is what a page can hold. Everything on this page can be edited, so try things out.

## Write the way you like

Use the toolbar, or type Markdown shortcuts: `#` and a space for a heading, `-` for a bullet, `1.` for a numbered list, `[ ]` for a to-do, `>` for a quote and three backticks for code. Type `/` on an empty line to insert any block.

**Bold**, *italic*, <u>underline</u>, ~~strike~~, <mark>highlight</mark> and `inline code` all work as you'd expect.

## Tasks

- [ ] Type `[ ]` and a space to start a to-do
- [ ] Open **Tasks** in the sidebar to see every to-do from every notebook
- [x] Tick them off from either place

## Link your thinking

Type `[[` to link to another page. The page you link to lists this one under **Backlinks**. Add #tags anywhere in the text, then browse them under **Tags**.

## Math and code

Inline math like $e^{i\pi} + 1 = 0$ sits in the text, and display math gets its own block:

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"
```

## Draw

Choose **Ink** in the toolbar, or type `/ink`, to add a drawing canvas. Pen pressure works with a stylus.

## Bring your notes

**Import → OneNote** reads `.one` sections and `.onetoc2` notebooks, handwriting included. **Import → Folder** reads Markdown folders such as Obsidian vaults. **Export** writes everything as Markdown with JSON sidecars, so you can open your notes without AnyNote.
